## 🌟 ویژگی‌های کلیدی پنل

- ⚡ **پشتیبانی کامل از تمامی پروتکل‌ها:** VLESS, VMess, Trojan, ShadowSocks, WireGuard, Hysteria 2, TUIC, MTProto
- 🔒 **پشتیبانی کامل از پروتکل‌های امنیتی:** REALITY, TLS, gRPC, WebSocket, XHTTP, XTLS Vision
- 📊 **رابط کاربری مدرن و سریع:** داشبورد بهینه‌شده به همراه زبان شیرین فارسی، تم تاریک/روشن و نمودارهای زنده مصرف ترافیک
- 👥 **مدیریت کاربران و اشتراک‌ها:** سیستم ساب‌سکریپشن پیشرفته، محدودیت حجم و زمان، محدودیت تعداد کاربر همزمان (IP Limit)
- 🤖 **ربات تلگرام هوشمند:** مدیریت اکانت‌ها، گزارش مصرف، اعلان انقضا و خرید
- 🛡️ **فایروال و امنیت داخلی:** مسدودسازی ترافیک مخرب، بلاک خودکار حملات Brute-Force و Fail2Ban

## 📥 راهنمای نصب سریع

جهت نصب آسان و خودکار پنل روی سرور لینوکس (Ubuntu, Debian, CentOS, AlmaLinux) دستور زیر را در ترمینال سرور خود اجرا کنید:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/GALEXY-PANEL/3x-ui/main/install.sh)
```

---

## 🔄 دستورات مدیریت پنل

پس از نصب، می‌توانید با دستور زیر در خط فرمان سرور منوی مدیریت پنل را باز کنید:

```bash
x-ui
```

### عملیات‌های پرکاربرد:

| دستور | عملکرد |
| :--- | :--- |
| `x-ui start` | شروع به کار پنل |
| `x-ui stop` | متوقف کردن پنل |
| `x-ui restart` | راه‌اندازی مجدد پنل |
| `x-ui status` | بررسی وضعیت فعال بودن پنل |
| `x-ui update` | آپدیت پنل به آخرین نسخه |
| `x-ui settings` | تغییر پورت، نام کاربری و رمز عبور پنل |
| `x-ui cert` | دریافت خودکار گواهینامه امنیتی SSL (Let's Encrypt) |
| `x-ui log` | مشاهده لاگ‌های زنده هسته و پنل |
